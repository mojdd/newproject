# 00 — نظرة عامة والمعمارية

## ١. المشكلة

طريق النجف–كربلاء يفتقر لتغطية اتصالات كافية أثناء الزحام المليوني للأربعينية،
والنت ينقطع بمساحات طويلة. الزوار يحتاجون يتواصلون ويتشاركون معلومات خدمية حيوية
(مبيت، ماء، إسعاف، حركة مواكب، طوارئ) لكن البنية الخلوية تنهار تحت الكثافة.

**الحل:** شبكة mesh لا-مركزية مبنية من تلفونات الزوار أنفسهم. ما تحتاج بنية تحتية،
وتشتغل **أحسن** كل ما زادت الكثافة — وهذا بالضبط ظرف الأربعينية.

## ٢. الستاك ومبرّراته

| الطبقة | الاختيار | السبب |
|--------|----------|-------|
| المنصّة | **Android native** | الجمهور ~كله أندرويد؛ BLE + الخلفية يحتاجون تحكّم native كامل |
| اللغة | **Kotlin** | لغة أندرويد الرسمية |
| الواجهة | **Jetpack Compose** | واجهات حديثة، بناء سريع |
| التزامن | **Coroutines + Flow** | إدارة شبكة/DB/حالات غير متزامنة |
| المدى القصير | **BLE (GATT)** | استهلاك بطارية منخفض، أساس الـ mesh المستمر |
| الباندويث الأعلى | **Wi-Fi Aware (NAN)** / Wi-Fi Direct | نقل بيانات أكبر؛ الدعم يختلف بين الأجهزة |
| التشفير | **libsodium** (`lazysodium-android`) | E2E مُختبَر؛ sealed boxes تناسب mesh لاتزامني |
| التخزين | **Room + SQLCipher** | قاعدة محلية مشفّرة |
| الخلفية | **Foreground Service** (`connectedDevice`) | يبقي التلفون عقدة relay وهو بالجيب |

**قاعدة ملزمة:** ماكو backend-as-a-service ولا اعتماد على سيرفر للتشغيل. السيرفر
**وجهة مزامنة انتهازية فقط** — يصرّف المخزون لمن يتوفّر نت، لا غير.

   │  Mesh: routing + forward     │  ← وحش ٢،٣ (وثيقة 02،03)
   ├──────────────────────────────┤
   │  Transport: BLE + Wi-Fi Aware│  ← وحش ٦ (وثيقة 06)
   ├──────────────────────────────┤
   │  Background survival         │  ← وحش ١ (وثيقة 01)
   ├──────────────────────────────┤
   │  Local storage               │  ← وحش ٧ (وثيقة 07)
   └──────────────────────────────┘
            ▲
            │ لمن تتوفّر نت → بوابة (وحش ٥، وثيقة 05)

## ٥. مفاهيم أساسية (مصطلحات)

- **Node / عقدة:** تلفون زائر مشارك بالشبكة، له `NodeId` مشتق من مفتاحه العام.
- **Relay / وسيط:** عقدة تمرّر رزمة مو موجّهة لها (تشوف blob مشفّر فقط).
- **Gateway / بوابة:** عقدة لمستها نت مؤقتاً فترفع المسموح للسيرفر.
- **Packet / رزمة:** وحدة البيانات اللي تنتقل بالـ mesh (تفاصيلها [وثيقة 14](14-wire-format.md)).
- **Trusted / موثوق:** جهة بادلتها مفتاحك وجهاً لوجه (QR) — يشوف اسمك وموقعك.
- **Stranger / غريب:** عقدة relay مجهولة — يمرّر بلا ما يقرأ.
- **Controlled flooding:** إعادة بث مُتحكَّم بها بدل routing منظّم ([وثيقة 02](02-wolf-routing.md)).
