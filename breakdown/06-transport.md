# وحش ٦ — نقل BLE (قطع ~١٠٠ سطر)

هذا الوحش هو **الأسلاك** اللي توصّل التلفونات ببعض عبر بلوتوث وواي فاي. أكبر وحش
وأطوله، لأن بلوتوث صعب ومتعب. 📡

تفاصيل: [docs/06-wolf-ble-transport.md](../docs/06-wolf-ble-transport.md)

| الرمز | الاسم | ~أسطر | شنو تسوي |
|-------|-------|-------|----------|
| T1 | فحص صلاحيات/محوّل BLE | ~100 | يتأكد البلوتوث مفتوح والصلاحيات موجودة |
| T2 | إعداد خادم GATT | ~200 | يبني «صندوق بريد» بلوتوث يستقبل منه الجيران |
| T3 | خادم GATT: استقبال رزمة | ~150 | يقرأ الرسالة اللي جار يكتبها لنا |
| T4 | خادم GATT: إرسال (notify) | ~150 | يرسل رسالة للجار المتصل بينا |
| T5 | عميل GATT: اتصال | ~150 | يتصل بجار قريب |
| T6 | عميل GATT: اكتشاف + كتابة | ~150 | يلگه صندوق بريد الجار ويكتب إله الرسالة |
| T7 | عميل GATT: اشتراك بالإشعارات | ~120 | يشترك حتى يستلم رسائل الجار |
| T8 | الإعلان (legacy) | ~120 | يبثّ «أني هنا» (اسم العقدة) للجيران |
| T9 | الإعلان الموسّع (BLE5) | ~150 | إعلان أكبر للأجهزة الحديثة |
| T10 | ترميز نبضة الحضور | ~100 | يحط اسم العقدة + إشارات صغيرة بالإعلان |
| T11 | الماسح + ScanFilter (شاشة مطفية!) | ~150 | يدوّر على الجيران، وبفلتر مهم حتى يشتغل والشاشة مطفية |
| T12 | نتيجة المسح ← جدول الجيران | ~120 | لمن يلگه جار، يسجّله بالدفتر |
| T13 | جدول الجيران | ~150 | دفتر فيه كل جار: قوة الإشارة، آخر ظهور، بطاريته |
| T14 | تقادم الجيران | ~80 | يمحي الجيران اللي اختفوا من زمان |
| T15 | تفاوض MTU | ~80 | يطلب حزم أكبر حتى نرسل أسرع |
| T16 | تقطيع الرزمة | ~120 | يقصّ الرسالة الكبيرة قطع صغيرة تنفذ ببلوتوث |
| T17 | تجميع الرزمة + مهلة | ~150 | يلزّق القطع الصغيرة ويرجّعها رسالة كاملة |
| T18 | مجدول الاتصالات | ~250 | يدوّر بين الجيران: يتصل، ينقل، يقطع، يروح للثاني |
| T19 | تتبّع حالة الاتصال + أخطاء | ~200 | يتعامل مع قطع الاتصال والأخطاء الكثيرة ببلوتوث |
| T20 | طابور الإرسال لكل جار | ~120 | يرتّب الرسائل اللي راح نرسلها لكل جار |
| T21 | إعادة المحاولة + تباطؤ | ~120 | لو فشل الإرسال، يحاول مرة ثانية بهدوء |
| T22 | كشف Wi-Fi Aware | ~100 | يشوف لو التلفون يدعم واي فاي المباشر السريع |
| T23 | جلسة Wi-Fi Aware + نقل | ~300 | ينقل بيانات كبيرة بسرعة لمن يتوفّر |
| T24 | واجهة النقل الموحّدة | ~150 | باب واحد يستعمله باقي التطبيق للإرسال/الاستقبال |
| T25 | ربط callbacks البلوتوث | ~150 | يوصّل كل أحداث بلوتوث المتفرقة مع بعض |

**المجموع:** ~3,680 سطر · 25 قطعة

> 🔴 صدق: هذا الوحش **يحتاج أجهزة تلفون حقيقية** للاختبار. المحاكي ما يكفي لبلوتوث.
> بس قطعتي التقطيع/التجميع (T16/T17) نختبرهم على الكمبيوتر.
