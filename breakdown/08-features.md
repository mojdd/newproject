# الميزات (قطع ~١٠٠ سطر)

هذي الأشياء اللي **يشوفها المستخدم ويستعملها** — تركب فوق الوحوش. كلها تحترم
[الخطوط الحمراء](../docs/10-red-lines.md): أرقام عن مكان/خدمة ✅، شخص بالاسم ⛔. 🧰

تفاصيل: [docs/09-features.md](../docs/09-features.md)

| الرمز | الاسم | ~أسطر | شنو تسوي |
|-------|-------|-------|----------|
| X1 | بث الموقع للموثوقين | ~150 | يرسل موقعك **لناسك بس**، مقفّل |
| X2 | استقبال/عرض الموقع | ~120 | يوريك وين ناسك الموثوقين |
| X3 | منطق الرسائل | ~200 | يرسل ويستقبل رسائلك مع الموثوقين والقريبين |
| X4 | المبيت: نشر/مطابقة | ~200 | صاحب نزل ينشر «عندي مبيت»، واللي يدوّر يتطابق |
| X5 | تجميعي: الوجبات | ~100 | أرقام الوجبات الموزّعة بكل محور |
| X6 | تجميعي: ماء/تواليت | ~120 | مواقع وزحمة الماء والتواليتات |
| X7 | تجميعي: إسعاف | ~120 | أماكن الإسعاف وحالتها |
| X8 | تجميعي: الكثافة/العدد | ~150 | كم زائر بكل محور + خرائط زحمة لتجنّب التدافع |
| X9 | تجميعي: حركة المواكب | ~120 | متى يتحرك كل موكب ومن وين |
| X10 | دليل الموردين | ~150 | محلات الجملة: موقع/بضاعة/سعر/توفّر |
| X11 | شفافية مالية الموكب | ~150 | دعم/صرف الموكب (شفافية كيان، مو شخص) |
| X12 | صحة عامة تجميعي | ~150 | أعداد الأمراض الشائعة بكل محور → إنذار مبكّر |
| X13 | زر الاستغاثة SOS | ~120 | يرسل نداء طوارئ **لجهة إنسانية** بأولوية عالية |
| X14 | بلاغ خطر بمكان | ~120 | يبلّغ عن ازدحام/حادث بمكان معيّن |
| X15 | ربط الميزات بالشبكة | ~150 | الغراء اللي يوصّل الميزات مع الوحوش تحت |

**المجموع:** ~2,120 سطر · 15 قطعة

> ⛔ كل ميزة تنفحص ضد [الخطوط الحمراء](../docs/10-red-lines.md) قبل بنائها.
