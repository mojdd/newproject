# وحش ١ — الخلفية (قطع ~١٠٠ سطر)

هذا الوحش يخلّي التلفون **يضل صاحي** يوصّل الرسائل وهو بالجيب. مثل حارس ما ينام. 💤❌

تفاصيل التصميم الكاملة: [docs/01-wolf-background-survival.md](../docs/01-wolf-background-survival.md)

| الرمز | الاسم | ~أسطر | شنو تسوي |
|-------|-------|-------|----------|
| B1 | هيكل الخدمة `MeshService` | ~100 | يبني الخدمة الأساسية ويبدأها/يوقفها (onCreate/onStartCommand/onDestroy) |
| B2 | الإشعار الدائم + قناته | ~100 | يصنع الإشعار اللطيف «نشط — يساعد بإيصال الرسائل» وقناة الإشعار |
| B3 | `START_STICKY` + إصلاح بلا intent | ~80 | يرجّع الخدمة لو النظام قتلها، ويتعامل مع رجوعها فاضية |
| B4 | `onTaskRemoved` إعادة تشغيل | ~80 | يرجّع الخدمة لمن المستخدم يمسح التطبيق من الشاشات المفتوحة |
| B5 | `BootReceiver` | ~100 | يشغّل الخدمة بعد ما يطفي ويشتعل التلفون |
| B6 | ربط نوع `connectedDevice` + صلاحيات | ~100 | يحدد نوع الخدمة الصح بالـ manifest ويفحص صلاحياتها (أندرويد 14) |
| B7 | طلب إعفاء البطارية | ~100 | يطلب من المستخدم يعفي التطبيق من توفير البطارية |
| B8 | جدول المسح الواعي لـ Doze | ~150 | يمسح BLE بفترات قصيرة ذكية حتى وقت نوم التلفون العميق |
| B9 | مدير ملفات الطاقة | ~150 | يبدّل بين 3 أوضاع: قوي / متوازن / موفّر بطارية |
| B10 | مراقب مستوى البطارية | ~100 | يسمع كم باقي بطارية ويبدّل وضع الطاقة تلقائياً |
| B11 | مدير `WakeLock` | ~100 | يصحّي المعالج **بس** وقت شغل الرسالة، وينام بعدها (يحفظ البطارية) |
| B12 | كشف نوع الجهاز (OEM) | ~100 | يعرف الجهاز شيمي لو سامسونغ لو هواوي… عشان يساعد صح |
| B13 | فتح صفحة Autostart لكل شركة | ~200 | يفتح الإعداد المخفي اللي يخلّي التطبيق يشتغل تلقائي (يختلف كل شركة) |
| B14 | نصوص شاشة الإرشاد | ~150 | كلام واضح يعلّم المستخدم شلون يضبط جهازه خطوة خطوة |
| B15 | نبضة قلب + حارس `AlarmManager` | ~150 | يدق كل فترة يتأكد الخدمة عايشة |
| B16 | كشف الموت + إعادة تشغيل | ~120 | يلاحظ لو الخدمة انقتلت ويحاول يرجّعها |
| B17 | حالة الخدمة (StateFlow) | ~100 | يخلّي بقية التطبيق يعرف الخدمة شغّالة لو لا |
| B18 | مرتّب الصلاحيات | ~150 | يطلب الصلاحيات بالترتيب: BLE ← موقع ← إشعارات ← بطارية |

**المجموع:** ~1,850 سطر · 18 قطعة

> 🔴 صدق: قطعتي B13/B14 (إرشاد الشركات) ما يضمنون 100%. بعض الأجهزة عنيدة. هذا حد
> معروف، مو خطأ بالبناء — تفاصيله بوثيقة التصميم.
